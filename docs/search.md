# 搜索框

根据查找任务和字段类型选择控件，不把所有列表字段都做成搜索项。

## 什么类型用什么框

| 字段类型 | 搜索形式 | 匹配与选择规则 |
| --- | --- | --- |
| ID、手机号、编号、SN、OpenID 等文本标识 | 关键词搜索 | 唯一标识、手机号、编号使用精确匹配 |
| 姓名、昵称等自然语言 | 关键词搜索 | 模糊匹配 |
| 有限枚举字段 | 下拉筛选 | 互斥且通常只选一个值时使用单选；需要多个值时使用多选 |
| 有明确按时间段定位需求的时间字段 | 日期范围选择器 | 只在有业务查询场景时加入，不因列表存在时间字段就默认加入 |

## 搜索框合并与拆分

- 同一业务实体、同一操作意图，可以共用一个搜索框，如“ID / 用户姓名”。
- 一个框支持多个字段时，分别说明每个字段的匹配方式，并注明“共用一个搜索框”。
- 匹配方式明显不同且属于高频入口时拆分：手机号独立，精确匹配，不与姓名模糊搜索混在一起。
- 不同业务实体分别设置，如家庭成员页的“主用户”和“成员”。
- 多个同类技术标识，在业务人员通常只掌握其中一个时可共用，如“平台用户ID / OpenID / UnionID”。

## 下拉多选

- 顶部必须有“所有”选项，动态选项分别带复选框。
- 点击“所有”表示不限条件，并清空其他勾选。
- 说明统一写“多选。所有+字段类型”，如“多选。所有+病史类型”。
- 动态枚举不写死具体值或选项数量。

## 字段说明怎么写

| 搜索项 | 搜索形式 | 说明 |
| --- | --- | --- |
| ID / 姓名 | 关键词搜索 | ID 精确匹配；姓名模糊匹配，共用一个搜索框 |
| 手机号 | 关键词搜索 | 精确匹配 |
| 状态 | 下拉筛选 | 单选 |
| 类型 | 下拉筛选 | 多选。所有+类型 |
| 创建时间 | 日期范围选择器 |  |

- “搜索形式”只写组件类型：关键词搜索、下拉筛选、日期范围选择器。
- 精确／模糊、单选／多选写在“说明”栏。
- 不写“已有”“新增”“保留”“现状支持”等历史状态。
- 不将实际页面没有的字段加入搜索项或说明。
